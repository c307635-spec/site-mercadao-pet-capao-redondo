# Site Mercadão Pet Capão Redondo

Projeto demonstrativo independente em React, Vite e Tailwind CSS.

## Incluído
- Catálogo demonstrativo com busca e filtros
- Rações, farmácia pet, higiene, acessórios e brinquedos
- Entrega, leva e traz e promoções
- Pedidos pelo WhatsApp
- Telefone, endereço, rota e horários
- Design responsivo

## Aviso
Produtos, preços, promoções, disponibilidade, horários e serviços são demonstrativos ou sujeitos à confirmação da empresa.

## Executar
```bash
npm install
npm run dev
```

## Produção
```bash
npm run build
```
